# ✅ Exercícios Resolvidos (VisuAlg)

Soluções em código de cada exercício proposto na apostila, extraídas do **Gabarito Oficial**, uma pasta por capítulo.

Cada arquivo é nomeado `exercicio-NN.alg`, correspondendo ao número do exercício no respectivo capítulo da apostila. Quando um exercício admite mais de uma solução correta, a alternativa aparece como `exercicio-NN-2.alg`.

> ⚠️ No Capítulo 12 (Projeto Prático Final), os exercícios 1 a 4 são **trechos a inserir** no algoritmo-base do sistema de cadastro de produtos (não são programas completos sozinhos) — isso está indicado no cabeçalho de cada arquivo. O exercício 5 é um algoritmo completo e independente.

Este material é destinado ao professor para conferência e correção. Para os alunos, recomenda-se liberar apenas a pasta [`/algoritmos`](../algoritmos) (exemplos) durante o curso.
