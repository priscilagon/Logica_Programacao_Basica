| `09-vetores/` | Capítulo 9 — Vetores |
| `10-matrizes/` | Capítulo 10 — Matrizes |
| `11-arquivos/` | Capítulo 11 — Arquivos |
| `12-projeto-pratico-final/` | Capítulo 12 — Projeto Prático Final (sistema de cadastro de produtos) |
